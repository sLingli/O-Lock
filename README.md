## 中文介绍

**O-Lock** 是一款专为 **OPPO / OnePlus/Realme** 用户打造的 Windows 智能锁屏工具。

它是为了解决 **OPPO 互联 (PC Connect)** 与 Windows 自带“动态锁”冲突的问题而生。

### 🧐 为什么要开发这个工具？(背景)

很多 OPPO 用户在使用“OPPO 互联”跨屏协同功能时会发现：**Windows 自带的“蓝牙动态锁”失效了。**

这是因为 OPPO 互联为了保持高速数据传输，会长期占用蓝牙通道或导致蓝牙连接不稳定，系统无法准确判断手机是否离开。

**O-Lock 的解决方案：**
我们不依赖不稳定的蓝牙 RSSI，而是直接监测 OPPO 互联的运行状态及其底层 **TCP 网络连接**（只看主程序 `O+Connect.exe` 到手机的会话连接）。
**只要 OPPO 互联还能传数据，O-Lock 就知道你还在！**

---

### 🧠 核心原理与工作流程

O-Lock 采用智能状态机机制，确保在各种场景下都能准确判断，绝不误锁。

#### 1. ⚪ 灰色状态：等待程序启动
- **触发场景**：刚开机，或电脑刚解锁。
- **逻辑**：监测 `O+Connect.exe` (OPPO互联主程序) 是否运行。
- **行为**：如果没运行，保持静默，**绝不锁屏**。

#### 2. 🟡 黄色状态：缓冲期 (Loading)
- **触发场景**：检测到 `O+Connect.exe` 启动了。
- **逻辑**：给予一段缓冲时间（默认 60秒），等待手机自动连接。
- **行为**：
    - **连接成功** → 立即转为 🟢 绿色。
    - **超时未连** → 视为手机不在身边，立即转为 🔴 红色并 **执行锁屏**。

#### 3. 🟢 绿色状态：守护中 (Monitoring)
- **触发场景**：手机通过 OPPO 互联成功连接（TCP 建立）。
- **逻辑**：每秒检测一次心跳。
- **行为**：
    - **连接断开** → 持续 9 秒（可在设置中调整）检测不到连接，执行 **锁屏**。

#### 4. 🔴 红色状态：已锁屏
- **触发场景**：手机离开或连接超时。
- **行为**：锁屏后程序暂停检测，等待下一次用户解锁屏幕，重置回 **⚪ 灰色状态**。

### 📥 安装与使用

1.  **下载**：在右侧 [Releases](https://github.com/sLingli/O-Lock/releases) 页面下载最新的 `O-Lock.exe`。
2.  **运行**：双击程序，无需安装。
3.  **托盘图标**：右下角会出现一个小圆点，颜色代表当前状态。
    - ⚪ 灰：等待 OPPO 互联启动
    - 🟡 黄：正在连接手机...
    - 🟢 绿：手机在线，放心使用
4.  **开机自启**：在托盘图标上 **右键** -> 勾选 **“开机自启”**。
5.  **设置**：在托盘图标上 **右键** -> **设置**，可修改进程名、离线容忍秒数、缓冲期等。
    全部配置保存在注册表 `HKCU\Software\OLock`。自 **v1.3.2** 起不再读取程序目录下的 `olock.config.json`。若从 v1.4.x 升级后需要使用热点（`172.16.x`）或 IPv6，可在设置中清空「允许 IP 前缀」以启用全私网与 IPv6 自动匹配。
6.  **v1.1 C# 重构版**

重构为 C#，大幅降低资源占用。

⚠️ 仅支持 Windows 10/11（x64）

| 文件 | 说明 |
|------|------|
| Lite.zip | 需安装 [.NET 8 运行时](https://dotnet.microsoft.com/download/dotnet/8.0) |
| Full.zip | 开箱即用，无需任何依赖 |

### 🧪 连接测试 (v1.4.0 新增)

托盘右键 → **连接测试…**（或在程序已运行时再次双击 `OLock.exe` 唤醒窗口），无需真的等到锁屏，就能验证工具是否正常工作：

- **立即检测**：打开窗口即自动检测，也可随时点击重测。🟢 已连接会显示命中的远程 IP 与进程 PID；🔴 未连接会给出诊断原因（主程序未运行 / 无已建立连接 / 连接 IP 不匹配并附样本）。
- **断开测试**：检测到手机在线后，从窗口内的引导入口点击 **开始断开测试**。测试走**真实监控链路**（离线倒数、托盘图标同步变红），到点仅**模拟执行**锁屏/睡眠指令——**全程屏幕不会锁定、电脑不会睡眠**，测试结束后自动进入等待重连保护（待手机重连后恢复正常守护，绝不会在测完后误锁屏/误睡眠）。

### 🔄 检查更新与自动更新 (v1.5.0 新增)

- **启动静默检测**：默认在程序启动后静默检查一次 GitHub 最新版本（可在 **设置** 中关闭「启动时自动检查更新」）；若无更新或网络不通保持完全静默，发现新版本时通过托盘气泡提醒。
- **程序内一键自更新**：托盘右键 → **检查更新…** 可查看当前版本（自动识别 `Lite` / `Full` 包体）与最新更新说明，点击 **立即更新并重启** 即可在应用内流式下载对应压缩包、原路径无感替换 `OLock.exe` 并自动重启（保留开机自启路径与系统托盘图标设置）。
